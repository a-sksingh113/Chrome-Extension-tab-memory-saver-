Privacy Policy for Tab Memory Saver

Tab Memory Saver does not collect, store, transmit, or share any personal or sensitive user data.

All processing is performed locally within the user's browser. The extension only uses Chrome-provided APIs to detect inactive tabs and suspend them to reduce memory usage.

No data is sent to any external servers.
No tracking, analytics, or advertising is used.
User preferences are stored locally using Chrome storage.

If you have any questions, you may contact the developer via the support email listed on the Chrome Web Store page.
